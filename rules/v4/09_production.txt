# 工程9：字幕焼込動画

## 入力
・現案件の最新「元動画」
・工程8で承認済みの字幕本文
・工程8の字幕密度QA記録（density_qa=PASS）
・現案件で確定したA/B
・BGMモード
・fixed_bgm.MP3
・asmr bgm.MP3

## 字幕密度引継ぎゲート｜最優先
工程8の内部記録に density_qa=PASS、effective_chars、density_min、density_max が無い場合は書き出さない。
工程9で本文を増減して密度を調整することは禁止。密度FAILなら工程8/6へ戻す。

## BGMゲート
BGMモード未指定なら、処理せず次だけを返して停止する。
「BGMは ①なし ②fixed_bgm ③ASMR のどれにしますか？」

BGMなし：元音声のみ
BGMあり／fixed_bgm：fixed_bgm.MP3を元音声の約1/2の音量で使用
ASMR：asmr bgm.MP3を元音声の約1/5の音量で使用
BGMは元音声を邪魔しないよう必要なら発話中だけ軽く抑える。元音声は消さない。

# 最重要｜編集元
字幕焼き込みは、現案件で最初に受け取った最新の元動画から行う。
以前の字幕入りMP4、位置修正版MP4、別案件MP4を加工元にしない。
完成済みMP4の部分補修は禁止。

# 音声確認
日本語音声がある場合、最初から最後まで実際に確認する。
書き出し前に内部で全発話対応表を作る：
・発話番号
・実際に聞こえた日本語音声
・音声開始
・音声終了
・対応する承認済み字幕
・字幕開始
・字幕終了
・音声開始より何秒前に字幕を出すか

ユーザーが「承認済み字幕をそのまま使っていい」と指定した場合、本文は工程8の内容を一文字も変えず、音声との対応・時刻だけを決める。

# 字幕タイミング
・各字幕は対応発話より遅れて出さない
・原則、発話開始の0.10〜0.20秒前に表示
・発話を言い切る前に字幕を消さない
・次の発話後も前字幕を残さない
・文章途中で不自然に切り替えない
・場面転換と自然な意味区切りが0.15秒以内なら場面転換へ寄せてよい
・全字幕を一律に前後移動しない
・字幕ごとに調整

# 字幕デザイン標準プリセット
案件内の最新ユーザー指定があればそちらを優先。
標準：
・中央揃え
・最大2行
・3行、4行は禁止
・かなり大きい
・極太の日本語ゴシック系
・太い黒ふち
・文字色：黄〜オレンジ中間。基準 #FFB300
・白帯なし
・背景帯なし

# 字幕位置標準
X：画面中央50％。字幕バウンディングボックス全体を画面幅10〜90％に収める。
Y：固定アンカーを画面高83.3％にする。
字幕バウンディングボックス全体を画面高62〜88％に収める。
全字幕でアンカー位置を変えない。
文字が長い場合は、位置を動かさず、まず2行化、次にフォントサイズを必要最小限だけ下げる。

例：2160×3840
X安全範囲：216〜1944px
Y安全範囲：2381〜3379px
固定アンカー：X=1080px、Y≈3200px

# 事前デザインゲート
全編書き出し前に最低3枚の確認画像を作る：
・最長字幕
・2行字幕
・背景が最も複雑な字幕
実測確認：
・2行以内
・X安全範囲内
・Y安全範囲内
・アンカー固定
・文字化けなし
・色 #FFB300 相当
・太字、黒ふち
・十分大きい
1つでもNGなら本書き出ししない。

# 映像編集禁止
・途中カット
・順番変更
・速度変更
・画角変更
・ズーム
・位置ずらし
・縦横比変更
・不要な黒画面削除
・元動画にない映像追加
09では字幕とユーザー指定BGMだけを追加する。

# 書き出し
・MP4
・H.264
・AAC
・元動画と同じfps
・元動画と同じ解像度、縦横比
・元動画と同じ総フレーム数
・faststart
・映像音声タイムスタンプ0秒開始

# 書き出し後QA
実際に確認：
・元動画秒数と完成秒数
・fps
・解像度
・元/完成フレーム数一致
・開始、25％、50％、75％、90％、95％、終了0.2秒前、最終フレーム
・全字幕について字幕直前、発話開始、発話終了
・字幕が1フレームでも遅い場合はその字幕だけ1〜3フレーム前へ修正
・最後までデコード
・音声が途切れない
・BGMモードと音量が指定どおり
・BGMなしなら新規BGMがない

# 修正ルール
位置や色だけの修正でも、加工済みMP4の上から補修しない。
現案件の元動画＋承認済み本文＋承認済み字幕時刻から最初から再書き出し。
本文修正指示がないなら本文は変えない。

# 出力
標準でMP4、必要ならSRT/ASS/QA記録を作れる。
ユーザーが「MP4だけZIP」と言った場合、ZIP内は英数字名のMP4 1本だけにする。

## 禁止事項
・BGM未指定のまま書き出す
・承認済み字幕本文を勝手に変える
・過去案件または完成済みMP4を字幕焼込元にする
・字幕位置を文字ごとに上下移動する
・3行以上にする
・未確認の同期を確認済みと報告する

# 完了条件
・音声対応表を作れた
・全字幕同期を確認した
・字幕安全範囲を実測した
・元動画とフレーム数一致
・最後までデコード
・出力ファイルが存在し0byteでない
・ZIP指定時は展開確認
満たさない場合「完成」と言わない。
